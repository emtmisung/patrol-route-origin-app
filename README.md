# 파세루 오리진 (FireSafe Route Origin) — 실동 버전

주소 목록과 순찰 조건을 넣으면 **실제 도로 거리·시간 기준**으로 소방 순찰 노선을 자동 편성하고,
결과를 카카오맵 길안내·QR·엑셀로 바로 내보내는 Streamlit 앱입니다.

- 배포 주소: https://faseru-origin.streamlit.app/
- 기획·제작: 임미성 (성주소방서)
- 좌표·도로거리: 네이버클라우드(NCP) Geocoding · Directions5 API (호출할 때마다 요금이 나갑니다)
- 출발부서 이름 검색: 카카오맵 장소검색
- 소방청 공공데이터 API는 **사용하지 않습니다** (필요한 데이터가 아니어서 연동 안 하기로 결정)

---

## 1. 사용 흐름

| 단계 | 화면 | 하는 일 |
|---|---|---|
| 접속 | 로그인 | 비밀번호 입력. "이 기기에서 자동 로그인"을 켜면 30일간 비밀번호 생략 |
| 1단계 | 기본정보 · 대상목록 | 순찰 제목, 출발부서(이름·주소 조회 또는 휴대폰 현 위치), 대상 목록 업로드 → 좌표 검색 |
| 2단계 | 순찰방법 | 5가지 순찰 업무 중 하나를 고르고 기간·차량·시간 조건 입력 |
| 3단계 | 노선 생성 · 결과 | 노선 계산 → 지도·카카오맵·QR·엑셀 결과 확인과 다운로드 |

각 단계 아래의 초록색 **"다음 단계로 이동"** 버튼은 필수 입력이 끝나야 눌리고, 누르면 다음 탭으로 넘어갑니다.

## 2. 순찰 업무 5종

| 업무 | 노선을 나누는 기준 |
|---|---|
| ① 지휘관 현장방문 | 방문 지휘관 수만큼 권역을 자동으로 나누고 구역별 이동거리·시간 계산 |
| ② 특별경계근무 | 명절·선거·축제 등 주요 대상을 가까운 순서로 노선당 5개소씩, 하루 1~2회 반복 |
| ③ 계절순찰 | 기간·수행자·차량·편도 제한·1회 최대시간 반영, 코스별 예상 방문횟수 계산. 편도 기준을 넘는 원거리 대상은 따로 표시 |
| ④ 예방검사 | 검사기한·가능 요일·제외일·팀 수·하루 가능시간·대상당 시간으로 하루 권장량 계산. 처리용량이 모자라면 누락 경고 |
| ⑤ 지리조사(센터용) | 전체 소화전을 인원·차량에 균등 배정해 월 10회 당번일 안에 점검. 센터 인쇄용 결과 제공 |

## 3. 그 밖의 기능

- **소화전 현장안내** — 엑셀 없이 소화전 주소 1건만 넣으면 출발지 → 소화전 카카오맵 길안내와 동료 공유용 QR을 바로 만듭니다.
- **대상 목록 파일** — CSV · XLSX · XLS · HWPX(한글 표)를 읽고, 대상명·주소 칸을 자동으로 찾습니다. 빈 양식(xlsx) 다운로드와 기능확인용 예시 18건을 제공합니다.
- **좌표 검색과 실패 처리** — 주소를 못 찾으면 행정리→법정리, 괄호 제거, 부번 제거 순서로 자동 보정해 다시 검색합니다. 그래도 실패한 대상은 한 건씩 "주소 수정 후 재검색", "좌표 직접입력", "이번 대상 제외", "지도에서 실제 위치 찍기(위성·일반지도)" 중에서 처리합니다.
- **결과물** — 노선별 지도(실제 도로 경로선), 카카오맵 길안내 버튼(경유지가 많으면 구간을 나눔), 노선별 QR, 최종 순찰표 엑셀, 카카오맵 링크 엑셀, 전체 QR 묶음(ZIP), A4 QR 인쇄용 HTML, 센터 지리조사 인쇄물.
- **작업 보관과 기기 간 이어하기**
  - 최근 작업 3개를 **이 브라우저에만** 7일간 보관합니다. 서버에는 저장하지 않습니다.
  - PC에서 만든 작업이나 최종 노선을 **일회용 QR(10분 유효, 1회 사용)**로 휴대폰에 넘겨 현장에서 카카오맵을 바로 실행할 수 있습니다. 휴대폰에서는 PC로 넘기는 일회용 링크를 만듭니다.
- **같은 조건으로 노선 재탐색** — 조건을 그대로 두고 다른 순서의 노선을 다시 찾습니다.
- **홈 화면 바로가기** — 로그인 화면의 안내대로 PC(Edge)·안드로이드(네이버 앱)·아이폰(Safari)에 앱처럼 추가할 수 있습니다. 앱 아이콘과 카카오톡 링크 미리보기 이미지가 설정되어 있습니다.

## 4. 비용·개인정보 보호

- 작업 1건당 NCP 호출은 **최대 3,000건**에서 자동으로 멈추고, 그때까지 만든 결과는 보존합니다. 결과 화면에 사용량이 표시됩니다.
- 같은 주소·같은 구간은 24시간 동안 다시 호출하지 않습니다(캐시).
- 파일에 위도·경도가 이미 있으면 좌표 검색을 하지 않습니다.
- 노선 편성은 직선거리로 가까운 후보 몇 곳만 골라 실제 도로 API로 확인하는 방식으로 호출 수를 줄입니다. 직선거리는 API가 실패했을 때만 비상 대체값으로 씁니다.
- **개인정보는 올리지 않습니다.** 대상명과 주소만 입력하도록 안내하고, 지리조사 조원 이름은 앱이 아니라 내려받은 엑셀에서만 적습니다.
- 공개 주소로 누구나 API를 쓰지 못하도록 앱 입구에서 비밀번호를 확인합니다.

```
  step1_basic.py           1단계 기본정보 · 대상목록 · 좌표 확인 · 소화전 현장안내
  step2_method.py          2단계 순찰방법 · 세부 조건
  step3_build.py           3단계 노선 생성 · 결과 · 다운로드
  settings.py              공통 상수, 비밀값 읽기
  geo.py                   NCP 지오코딩·길찾기 호출, 주소 보정
  routing.py               노선 편성 알고리즘(최근접 이웃 · 장거리 분리 · 지리조사 배정)
  upload.py                대상 목록 파일 읽기, 빈 양식
  storage.py               브라우저 작업보관 · 자동로그인 · 휴대폰 전달(암호화)
  maps.py                  folium 지도
  exports.py               카카오맵 링크 · QR · 엑셀 · 인쇄용 HTML
  ui.py                    공통 화면 요소, 단계 이동 버튼, 공유 미리보기·아이콘 설정
  styles.py                공통 CSS, 아이콘 그림
geolocation_component/     휴대폰 GPS 현재 위치 컴포넌트
assets/                    앱 아이콘, 웹 매니페스트, 링크 미리보기 이미지
tests/smoke_test.py        자동 점검(가짜 API로 전체 흐름 실행, 비용 0원)
.github/workflows/keepalive.yml   5분마다 접속해 앱이 잠들지 않게 함
```

수정할 때는 해당 기능이 있는 파일만 열면 됩니다. 예: 예방검사 조건 화면은 `step2_method.py`, 노선 계산 방식은 `routing.py`.

## 6. 비밀값 (Streamlit Secrets)

코드와 GitHub에는 절대 넣지 않고 Streamlit Cloud의 **Settings → Secrets**에만 넣습니다.

```toml
APP_PASSWORD = "앱 접속 비밀번호"
NCP_CLIENT_ID = "NCP Client ID"
NCP_CLIENT_SECRET = "NCP Client Secret"

# 선택 항목
# MOBILE_TRANSFER_SECRET = "휴대폰 전달 QR 암호화용 값 (없으면 NCP 키로 대신함)"
# APP_PUBLIC_URL = "https://faseru-origin.streamlit.app/"
```

- 비밀값은 사용할 때마다 새로 읽으므로, Secrets를 바꾸면 앱 재시작 없이 반영됩니다.
- `APP_PASSWORD`를 바꾸면 기존 자동 로그인은 모두 풀립니다.

## 7. 실행과 배포

**PC에서 실행**

```bash
pip install -r requirements.txt
cp secrets.toml.example .streamlit/secrets.toml   # 실제 값 입력 (.gitignore로 GitHub에 안 올라감)
streamlit run app.py
```

**배포** — `main` 브랜치에 올리면 Streamlit Community Cloud가 자동으로 다시 배포합니다.

- Streamlit은 `requirements.txt`에서 **1.64.0으로 고정**했습니다. 단계 이동 버튼이 이 버전의 탭 기능을 쓰고, 새 버전이 나와도 앱이 갑자기 바뀌지 않게 하기 위해서입니다. 올릴 때는 아래 자동 점검을 통과한 뒤에 올립니다.
- 배포 후 화면이 이상하면 Streamlit Cloud 관리화면에서 **Reboot app**을 한 번 누릅니다.

## 8. 자동 점검

코드를 고친 뒤 배포 전에 실행합니다. 실제 API를 부르지 않으므로 요금이 나가지 않습니다.

```bash
python tests/smoke_test.py              # 로그인 → 좌표검색 → 소화전 현장안내 → 5종 노선 생성
FAIL_ONE=1 python tests/smoke_test.py   # 주소 1건 좌표 실패 상황
```

`점검 완료: 노선 생성 5/5종 · 오류 0건`이 나오면 통과입니다.

## 9. 활용 범위 안내

자동 생성 노선은 참고안입니다. 현장 여건과 출동 상황은 담당자가 검토해 최종 노선을 정하고,
지휘관 현장방문은 현장지휘관의 판단과 공식 지휘체계를 우선합니다.
